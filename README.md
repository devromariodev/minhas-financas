# Minhas Finanças

Controle financeiro pessoal simples, offline, que roda no celular (Android e iPhone) sem loja de apps.

- Lançamentos rápidos pelo botão **+**, com parcelas projetadas nos meses seguintes
- Compras no cartão de crédito caem no mês da fatura (fechamento e vencimento)
- Lançamentos fixos que repetem todo mês (salário, aluguel, assinaturas)
- Marcar como pago/recebido e ver quanto falta pagar no mês
- Limite mensal por categoria
- Painel personalizável, categorias com cor, lista ou tabela com filtro, tema claro ou escuro
- Backup em arquivo (exportar e importar), com lembrete semanal

Os dados ficam **somente no aparelho** (armazenamento local do navegador). Este repositório guarda só o código do app.

Como instalar: veja [INSTALAR.md](INSTALAR.md).
